Source: https://github.com/google/fonts/tree/main/ofl/fredoka
Downloaded variable font: Fredoka[wdth,wght].ttf, from the Google Fonts repository.
Static Regular (weight 400) and SemiBold (weight 600) instances at width 100 were generated
with fontTools.varLib.instancer to use in Unity's font importer. No outlines were edited.
The source download hash and derived file hashes are recorded in Artifacts/CartoonFonts/Source.json.

The original font license is also included at
Assets/StreamingAssets/ThirdPartyNotices/Fredoka-OFL.txt so it accompanies player builds.
